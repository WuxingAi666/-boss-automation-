# BOSS 直聘 AI 智能助手

基于 **Tampermonkey + FastAPI** 的 BOSS 直聘自动化辅助工具，帮助求职者更高效地管理投递与沟通。

## ✨ 功能特性

- **一键海投**：批量筛选岗位并自动发起沟通，显著提升投递效率
- **DeepSeek 自动回复**：基于大模型理解岗位 JD 与历史对话，生成贴合的沟通话术
- **实时监控**：实时追踪投递状态与已读 / 回复情况，数据看板可视化

## 🛠 技术栈

| 层 | 技术 |
| --- | --- |
| 前端脚本 | Tampermonkey（JavaScript） |
| 后端服务 | FastAPI（Python） |
| 大模型 | DeepSeek API |
| 通信 | RESTful API |
